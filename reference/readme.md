청각장애 수업 도우미
기능
* 수업 내용 실시간 STT로 변역→ 학교별 시간표 데이터 끌어옴(NEIS 학급별 시간표 공공데이터 API) →과목별 모호한 단어 파인튜닝
    * 사용자의 다음 시간표 정보 가져오기 → 해당 수업 맞춤형 STT? 제공
        * 기능 플로우1단계: 공통 STT 모델
            * Whisper / KoSpeech / Conformer 계열
            * AI Hub 한국어 강의 음성으로 보정
        * 2단계: 과목별 용어 보정예를 들어 수학 시간에 STT가“미분계수”를 “믿음 개수”로 잘못 인식할 수 있잖아?그래서 과목별 용어사전을 둬.
            * 수학: 함수, 미분, 적분, 벡터, 행렬
            * 과학: 세포, 전류, 산화, 질량, 운동량
            * 사회: 민주주의, 시장경제, 기본권, 세계화
            * 국어: 주제, 서술자, 비유, 상징, 문맥
        * 3단계: 과목별 RAG수업 transcript를 요약할 때, 과목별 교과 데이터/용어사전에서 관련 개념을 검색해서 붙여주는 방식.4단계: 필요하면 LoRA 어댑터정말 과목별 특화가 필요하면 모델 전체를 갈아끼우지 말고,
            * 공통 요약 모델
            * 국어 LoRA
            * 수학 LoRA
            * 과학 LoRA
            * 사회 LoRA
        * 이런 식으로 가는 게 현실적이야.
* 수업별 요약 노트
    * 학습 확인 문제 생성
    * 보통 필기는 교사의 말을 듣고 중요한 부분을 교과서/교재에 필기를 진행하는데 , 수업 내용 습득에 어려움을 겪는 농인 특성 상 즉각 필기가 불가능
* 핵심 개념, 과제 안내 등 중요한 기능 하이라이트 (실시간 가능?)“중요도 표시” 기능단순히 STT로 모든 말을 받아쓰면, 청각장애 학생 입장에서는 무엇이 중요한지 판단하기 어렵습니다. 실제 수업 필기는 교사가 말하는 내용 중 핵심 개념, 시험 포인트, 과제 안내를 골라 적는 과정이기 때문이에요.그래서 실시간 자막 화면에 다음 표시를 넣을 수 있어요.
    * 핵심 개념: “중요 개념”
    * 시험 관련 언급: “평가/시험 가능성”
    * 과제 안내: “숙제/제출”
    * 교사의 강조 표현: “다시 말하면”, “중요해요”, “시험에 나올 수 있어요”
    * 판서 연계: “칠판/자료 참고”
* 예를 들어 수학 시간에 교사가 “여기서 중요한 건 미분계수는 순간변화율이라는 거예요”라고 말하면, 앱이 실시간 자막 아래에 [핵심 개념] 미분계수 = 순간변화율처럼 정리해주는 방식입니다.
